# Logo Ambawbio Suite

Tous les fichiers de ce dossier sont **entièrement vectorisés** (aucune dépendance aux polices) : utilisables pour le web, l'impression, la broderie, l'enseigne et l'autocollant.

| Fichier | Usage |
|---|---|
| ambawbio-horizontal-{couleur,noir,blanc}.svg | Logo principal : symbole + « AMBAWBIO » + « SUITE » |
| ambawbio-vertical-{couleur,noir,blanc}.svg | Symbole au-dessus |
| ambawbio-symbole-{couleur,noir,blanc}.svg | Monogramme seul (icône, tampon, petites tailles) |
| ambawbio-symbole-thermique.svg | Noir pur #000, pour tickets 58/80 mm |
| source/*-texte.svg | Mêmes logos avec le texte modifiable (`<text>`, nécessite Archivo et IBM Plex Sans installées) |

## Construction
- Logotype « AMBAWBIO » : **Archivo Expanded ExtraBold** (largeur 125 %) compressé horizontalement à 96 % pour obtenir la largeur 120 % de la charte, approche +1,4 u à 34 u de corps. Approximation fidèle de l'instance variable Archivo wght 800 / wdth 120 utilisée dans les maquettes.
- Descripteur « SUITE » : **IBM Plex Sans SemiBold**, approche +42 %.
- Symbole : deux chevrons (grille 48 × 48). Couleurs : latérite #B4532A (chevron haut), charbon #1E1B18 (chevron bas), « Suite » #8E3507.
- Vectorisation réalisée avec opentype.js à partir des fichiers officiels (OFL 1.1) : Omnibus-Type/Archivo et IBM/plex.

## Règles d'usage
- Zone de protection : la moitié de la hauteur du symbole sur les 4 côtés.
- Tailles minimales : horizontal 96 px / 25 mm ; symbole 16 px / 5 mm ; broderie 30 mm.
- Interdits : déformer, ajouter ombres ou effets, changer les couleurs, poser sur un fond chargé, recomposer (symbole à droite, etc.).
