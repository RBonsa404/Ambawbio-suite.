# Icônes

**Base :** [Lucide](https://lucide.dev) (licence ISC) — paquet `lucide-angular` ou SVG inline. Trait 2 px, extrémités et jonctions arrondies, grille 24 × 24, `stroke="currentColor"`.

Icônes Lucide utilisées dans les maquettes : shopping-cart, scan-barcode, search, plus, minus, trash-2, receipt, banknote, wallet, calculator, package, warehouse, truck, users, user, user-plus, store, chart-column, book-open, file-text, printer, bluetooth, lock, settings, sun, menu, cloud-off, cloud-check, refresh-cw, clock, triangle-alert, badge-check, circle-check, circle-x, circle-alert, timer-off, info, check, list-ordered, calendar-clock, flask-conical.

**Sur mesure (ce dossier, même grille) :** `sac.svg`, `bidon.svg`, `carton.svg`, `palette.svg`, `mobile-money.svg`, `facture-certifiee.svg`, `hors-ligne.svg`, `synchronisation.svg`, `plage-numeros.svg`, `terminal-caisse.svg`, `imprimante-thermique.svg`, `ifu.svg`. Ce sont des premières versions à affiner ; elles respectent la grille Lucide pour se mélanger sans rupture.

**Opérateurs Mobile Money :** aucune icône ni logo. Composant `puce-operateur` = nom en texte (« Orange Money », « Moov Money », « Wave ») dans une puce neutre (bordure 1,5 px `texte`, fond `surface`).

**Règle :** en caisse, une icône est toujours accompagnée d'un libellé visible.
